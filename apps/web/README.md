# @zpcrweb/web

Web app for visualizing Bio-Rad CFX `.zpcr` files, built on
[`@zpcrweb/core`](../../packages/core).

**Status:** scaffold only. The application is planned work — see the root
[`TODO.md`](../../TODO.md) for the feature roadmap (file upload, run overview,
amplification-curve charts, plate heatmaps, and a raw file browser powered by the library's
low-level archive API).
